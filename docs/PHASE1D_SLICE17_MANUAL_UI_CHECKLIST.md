# Slice17 属性窗口人工清单

状态：依用户要求暂缓，构建和普通native回归不替代真实窗口体验。只使用自有普通用户测试文件/目录。

- 单文件右键属性与Alt+Enter打开同一个Blink只读属性窗口；名称/位置可选择复制，类型、精确字节/磁盘占用、精确到秒的创建/修改/访问本地时间和只读/隐藏等属性与实际文件一致。
- 单目录包含嵌套/空目录，后台逐步更新文件/子目录数量及大小，界面可响应。多选文件/目录汇总，硬链接名称分别计算；目录junction不跟随目标，稀疏文件大小和占用区分。
- 缺失、来源同名替换、权限/占用导致部分读取失败时保留已知结果，明确显示已统计和错误位置，不把部分值显示为完整总量。
- 大目录统计时关闭属性窗口、导航、切换/关闭标签或退出应用，旧结果不更新新的窗口；关闭即合作取消，当前目录枚举I/O结束后停止。
- 正在复制/移动等任务时，可对已有稳定页面打开只读属性；正在导航/重投影时遵循统一命令忙状态。单个模态属性窗口不叠加其它操作输入对话框。
- 检查窄窗口、长路径/名称、中英文资源、文本滚动、键盘关闭和焦点返回。普通属性窗口不弹出提权、不会修改只读/隐藏属性。

完整Shell元数据/ACL编辑、属性修改、预览/缩略图不因此纳入本轮；拖放、Merge/Replace及后续远端继续按整体计划推进。

当前最多捕获1024项，超出时应明确提示缩小选择。多个类型/时间不同应显示多个值，不用首项冒充全部；未知时间不显示1601。
