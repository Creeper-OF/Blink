# Phase 1D Slice 3 — 单普通文件复制与剪贴板人工检查

状态：全部待执行；按用户要求暂缓人工验收。普通native回归不代替以下人工体验。

- [ ] Blink普通目录中选一个普通文件，Ctrl+C/右键复制；到另一个目录Ctrl+V/背景粘贴，源保留且内容一致。
- [ ] Blink→Explorer和Explorer→Blink单普通文件复制正确，未实现的Cut/目录/多文件/虚拟对象明确提示。
- [ ] 原目录粘贴或已有同名目标不覆盖；操作栏重试允许改名后复制，取消输入不创建。
- [ ] 复制大文件时字节进度及时、取消有效、没有假成功；源保留，清理失败残留信息可见。
- [ ] Unicode/长路径文件正确，ADS/压缩/稀疏/加密/云文件明确提示不支持。
- [ ] 预复制之后源对象被替换，Blink自己剪贴板仍有效时不复制替换对象，提示重新复制。
- [ ] 粘贴准备中切标签/导航/关闭，不在迟到回调中提交错误目标；复制中关窗不等待后台。
- [ ] 相关目的目录标签完成后刷新，另一个目录/搜索标签不被切换；新建/重命名及其冲突重试正常。
- [ ] 地址栏/搜索框/名称输入中Ctrl+C/V仍为文本行为，系统键盘及窗口标题栏体验保持。

本刀不提供Replace/KeepBoth、目录递归、剪切/移动、Drag & Drop、回收站/永久删除；不把Phase1D标为完成。
