# Slice11 多目录/混合复制人工验收清单

状态：全部暂缓，自动普通开发检查不代替人工体验。使用自有临时目录，禁止覆盖实际资料；不需要真实IndexService。

- [ ] 选择多个普通目录，Ctrl+C/右键复制，另一标签Ctrl+V/背景粘贴；顺序、空目录、嵌套目录、Unicode名字及ADS正确。
- [ ] 文件和目录混合多选，Blink→Blink、Explorer→Blink、Blink→Explorer互操作；仅COPY，不误删源。
- [ ] 目录同名弹窗呈目录文案，Merge/Replace禁用；Skip/KeepBoth/Cancel只决定当前项，已完成前缀不重做，未开始尾项不伪报完成。
- [ ] 复制到原父目录，目录保持完整名字后加(2)编号；多次同源项逐项决定，不擅自去重。
- [ ] 多目录状态显示顶层项数量、当前目录files/dirs及当前文件字节；任何一个文件100%不能显示整个队列完成。
- [ ] 目录已创建root后取消或失败，保留实际partial路径/数量；手动改名重试不接管已有树，旧partial仍显示并刷新原目的标签。
- [ ] 出现冲突后离开目录、切标签、A→B→A或关闭窗口，迟到dialog/preparation不复活，不阻塞界面；其它标签同身份目录正确刷新。
- [ ] 失效来源、后项junction/特殊存储、超过1024项或4MiB有效负载时给出清楚错误；失效捕获不能提交成功前缀。

原有Slice9/10及更早人工门禁仍独立待执行。本清单不授权服务提权、管理员/MFT验收或用户实际剪贴板自动操作。
