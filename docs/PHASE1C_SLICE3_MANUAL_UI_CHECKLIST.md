# Phase 1C Slice 3 — 待执行的搜索界面验收

状态：**未执行 / 用户要求人工验收暂缓**。当前开发验证以 PROGRESS 和对应 native-validation.json 为准；本清单不代表已经启动产品界面或真实服务。

使用普通用户权限、当前 Release 产物和既有已验收服务/有效索引。服务状态切换遵循原人工流程，本轮不安装服务、重建索引或运行全卷 MFT 验收。

- Ctrl+F/Ctrl+E 聚焦搜索框；Enter 提交，Escape/返回按钮退出；Back 从搜索返回原文件夹而不消耗目录历史。F5 重新查询当前已提交查询，不能擅自提交尚未确认的输入草稿。
- 两个标签分别保持查询、范围、匹配模式、结果和结果选择；切换标签不重新枚举目录或自动重复搜索。连续提交保留最新意图，已取消或关闭标签的旧响应不得覆盖当前页；窗口保持可交互。
- All indexed local volumes 与 Current Folder 的 known-hit/miss；当前目录必须排除 sibling prefix、仅大小写不同的其它目录和已替换目录。alias/reparse/不受支持范围明确提示，不对全卷 DFS 降级。
- 单卷 Busy/Unavailable 保留其它卷结果，进度没有卷根时不错误归到该卷；重试只补同一次查询未完成的卷。新查询/F5 丢弃旧查询的完成记录。达到结果上限必须显示限制。
- 服务不可用时可以继续本地浏览；服务恢复后可重试。状态面板自动查询不与窗口内的搜索请求交错切换活动索引。错误、部分结果和正常无结果文案可区分。
- 搜索列表滚动与分批数据填充流畅，未完成的填充在标签切换/新查询后失效；隐藏项目开关遵循窗口共用策略，系统属性项目保持排除。列表选择不能改变原目录选择。
- 双击实际命中的行、键盘 Enter、“打开”和“定位”操作正确行；未选中行双击不能操作旧选择。硬链接的每条路径都能保持独立目标。
- 文件 Open 使用当前用户关联派发；目录 Open 导航到该目录；Locate 导航父目录并在新枚举后选择身份与名称匹配的行。文件/父目录被改名、移动、删除或同名替换后，显示已变化/无法定位，不能打开或选择其它对象。
- 在搜索、身份验证、目录浏览或关联打开在途时切换/关闭标签及窗口；没有旧 UI 回调、窗口冻结、残留测试进程或崩溃。原地址输入、三视图、标题栏空白拖动和导航滚轮正常。
- 中英文、明暗主题、键盘与窄窗口/DPI 布局；名称、完整路径、源卷、卷状态和错误可读，按钮可达。

记录产物 SHA-256、环境与逐项结果；普通 fake response/fixture 检查不能替代真实服务与交互验收。Phase 1C 及整个项目的完成状态独立于本清单。
