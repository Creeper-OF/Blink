## 默认范围与高级选项

| 当前标签页位置 | 默认搜索范围 |
| --- | --- |
| 此电脑（能看到C、D磁盘） | 所有本地磁盘，分别显示各盘索引状态和结果 |
| C盘根目录或C盘内任意目录 | 整个C盘 |
| D盘根目录或D盘内任意目录 | 整个D盘 |

搜索结果区域的“高级搜索”默认折叠。可以选择跟随当前位置、所有本地磁盘、指定磁盘、当前文件夹或指定目录。指定多个盘符可输入`C:;D:`，也接受逗号、空格分隔；目录使用完整本地路径，如`D:\Work`，或点“使用当前位置”。文件夹范围默认包含子目录，可取消勾选以只搜索直接子项。名称模式沿用包含、前缀、扩展名、完全匹配。

每个标签页独立保留本次设置；手动指定范围优先于位置跟随，切回“跟随当前位置”恢复默认。修改控件只保存草稿，按搜索或回车才查询；重试和当前搜索刷新沿用已提交条件。提交时同步读取搜索框与当前标签的高级控件，避免异步TextChanged使最新字符遗漏；隐藏的旧控件不再修改其它标签。

## 实现边界

沿用原SearchState/Coordinator/TabRecord和独立搜索结果展示，没有增加第二套查询路径。FollowLocation只存在于标签意图，实际请求明确解析为全盘或当前盘；当前盘和指定盘符不会调用磁盘发现，也不会向其它盘提交搜索。

目录非递归查询新增只读`SearchDirectChildren=7`，复用既有Request字段、帧布局和协议版本1，原命令1–6保持。服务共用原SearchRequest和FastIndex，精确父目录过滤在limit之前执行，避免深层命中先占满结果名额。BLK5磁盘格式不变；新服务继续兼容原普通Search客户端。目录身份和结果打开/定位沿用既有路径；本轮没有新增本地防护平台。
