# Phase1D Slice5 — 多文件复制队列人工检查

状态：全部待执行。按用户要求人工验收暂缓，不启动生产窗口或操作用户实际剪贴板；普通native检查不等同人工体验通过。

- [ ] 通过多选/Ctrl+C/右键复制，文件顺序及完整路径正确；外部资源管理器复制多文件后可在Blink粘贴。
- [ ] 混入目录、reparse/虚拟文件、无效路径或超出限制时整批明确失败，不能只复制可用的前几项。
- [ ] 文件准备阶段可取消，准备完成到UI提交间的迟到取消也不能启动复制；关闭窗口不等待元数据/剪贴板worker。
- [ ] 两个以上文件按队列串行复制，同名项出现Skip/KeepBoth/Cancel，选择仅作用当前项；Replace仍禁用。
- [ ] 前项成功、后项冲突或失败时前项副本保留，余项不开始；改名重试继续当前队列，不重做已完成项。
- [ ] 重复源、不同名称硬链接、Unicode/emoji/长路径和附加$DATA流复制完整，无隐式去重或静默改名。
- [ ] 当前文件字节与批次copied/skipped/failed/cancelled/remaining计数区分，单项100%不能显示整批完成。
- [ ] 复制中、两项之间及等待冲突时取消，不删除源或撤销此前成功；最后一项真正提交后的晚取消仍显示成功。
- [ ] 遇未完成副本后重试，仍可看到此前真实partial报告及路径，不把重试当作旧副本已清理。
- [ ] 同目标identity目录改名后的显式重试，只重绑未完成项到当前路径；换入的新目录对象不能接收旧队列。
- [ ] 导航/切标签/关闭冲突对话框后旧回调不推进新位置；有未开始队列时新mutation不会无声覆盖它，可以明确取消队列。
- [ ] Blink发布与接收的COPY意图正确，系统剪贴板被其它程序改写后不误用旧source身份；扩展DOS路径匹配保留原身份。
- [ ] 每项真实committed或partial只对目的父identity相关标签刷新；视图、重命名、新建和既有单文件复制继续正常。

目录递归、目录Merge、Replace安全覆盖、Move/Cut、DragDrop及删除仍是后续独立工作。
