# 与 Blink 一致的搜索结果菜单

> 2026-11-08 后续：普通目录与搜索已共用外观工具，39项界面回归全过并发布，详见 [菜单同步记录](FOLDER_MENU_SYNC_HANDOFF.md)。本页保留上一轮搜索外观基线。


按用户的新要求，将搜索结果的常用右键菜单改为 Blink 自己的 WinUI 菜单。实现、两配置构建/回归与18项生产界面检查均已完成。已确认之前由本代理打开的窗口没有文件操作/未完成对话框，正常关闭后发布6个变化文件并打开新版；没有强杀用户进程。

## 外观与操作

主菜单复用 Blink 的 WinUI 控件与当前窗口主题：8像素圆角、系统主题配色和阴影、16像素 Fluent 图标、紧凑分组以及快捷键提示。主菜单直接提供打开、剪切、复制、粘贴到所在目录、复制完整路径/父目录路径、定位、重命名、删除和属性。

“压缩与更多系统选项…”保留完整 Windows 菜单，Bandizip 等已注册扩展从该入口继续使用。第三方菜单在这个二级入口中仍由系统绘制；本轮没有把任意第三方 owner-draw 菜单转换成另一套自绘控件，也不为压缩软件各写一套适配。系统属性页保持完整原生功能。

## 实现边界

- 新增`SearchContextMenuPresentation`仅负责主菜单展示；普通操作继续调用已验证的`ExecuteSearchContextCommand`及原有剪贴板/文件操作队列。
- 展示主菜单不启动ShellMenuHost或加载第三方扩展；只有属性和系统扩展入口使用原生helper。索引、协议、服务和存储格式不变。
- 保留查询/标签/文件操作代次校验。菜单自身先使旧回调失效，再关闭；旧菜单的Closed事件不会取消新打开的系统菜单。切换查询、标签或关闭窗口时旧菜单不能复活。
- 菜单坐标使用XamlRoot逻辑坐标，在anchor内反变换；系统入口沿用原ClientToScreen和DPI转换。快捷键提示不新增全局重复注册。
