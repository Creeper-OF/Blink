# Slice16 删除与回收站人工清单

状态：依用户要求暂缓。普通native测试不替代真实窗口交互，只使用普通用户自有测试目录；本轮未启动Blink窗口或操作用户剪贴板。

- 选中文件、非空文件夹或多项，按Delete或右键删除，检查项目进入Windows回收站，来源列表更新，状态显示实际回收根项数量。到系统回收站手动恢复，确认内容与名称正常。
- Shift+Delete或永久删除菜单只出现一次确认，显示项目数量及名称；默认焦点为取消。取消不产生操作，明确确认后才永久删除所选项。
- 永久确认期间来源导航已变更时，旧选择不在新页面执行，给出命令已过期反馈。关闭窗口后没有迟到确认。
- 文件被其它程序占用时显示系统错误，关闭占用后重试。多项队列中间失败时，跳过后继续尾项；前面完成项不重复，取消保留真实已完成数量。
- 永久删除非空目录途中取消或子项失败时，若根仍在应显示可能部分删除，保留剩余来源并刷新。重试处理原剩余根，跳过继续其它选中项，不宣称整体回滚。
- 在其它标签打开待删除目录及其子目录，再从父目录删除该根；两个标签退回父目录，地址栏、标题和前进/后退路径一致，监听可继续更新。用户正在去其它位置的导航保持。
- 检查只读文件、硬链接、目录junction对象、长中文路径，确认只对所选名称生效，junction目标内容保留。权限不足显示正常错误，不额外弹出提权流程。
- 检查无法进入回收站的真实可移动卷环境：普通删除应明确失败，永久删除只能由用户显式选择和确认。此环境当前未验证，不以模拟的非回收标志否决代替。

目录合并/替换、拖放、属性、外部performed-effect与剪切外观反馈，以及后续SFTP/自建网盘仍待开发。当前人工验收继续暂缓。
