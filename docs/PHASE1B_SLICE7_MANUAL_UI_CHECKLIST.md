# Phase 1B Slice 7 人工验收

本 Slice 提供 Blink 自有文件区菜单及命令反馈；实际复制、剪切、粘贴、新建、重命名、删除与产品属性仍属于后续 Phase 1D。请在普通用户可写的测试目录中验证，保留原 Slice 4/5/6 的独立门禁。

- 在详细信息、列表和网格中右键文件/目录：菜单目标正确，未选中项成为选中项；已选中项保留多选，两个硬链接行不合并。
- 右键空白和空目录：显示粘贴、新建文件夹、刷新、查看和排序；保留原选择及地址草稿。
- 打开选中的目录、打开有系统关联的文件：复用现有打开路径；多选时打开、重命名和属性明确不可用。
- 菜单中切换三种视图、四种排序字段和升降序：地址、历史与有效选择保留，菜单与工具栏状态一致。
- 外部新增/删除文件后菜单刷新：列表与目录事实一致；This PC 支持打开位置、刷新和视图，文件系统专属命令及排序不可用。
- 文件区验证 Menu 键、Shift+F10、F2、Delete、Shift+Delete、Ctrl+C/X/V、Ctrl+Shift+N。未开放操作明确提示且不改动文件或系统剪贴板；地址编辑器的文本快捷键保持文本语义。
- 菜单打开后切换标签、目录或视图：过期入口不作用于新页面。关闭窗口及触摸长按转为移动手势时菜单安全取消。
- 标签与“＋”按钮之后、最小化按钮之前的空白能拖动窗口；新增/关闭标签、缩窄窗口后仍正确，已有标签与窗口按钮正常操作。

`scripts/run-blink-context-menu-smoke.ps1` 使用受控窗口按键消息及 UI Automation，不代替实物鼠标、触摸、系统快捷键和多显示器验收。标题栏系统鼠标拖动探测位于本机忽略目录 `.build/titlebar-drag`，要求 Windows 桌面已解锁且测试窗口处于前台。
