# Slice15 文件夹位置跟随人工清单

状态：依用户要求暂缓；普通native测试和构建不能替代真实窗口体验。仅使用普通用户自有测试目录。

- 分别在标签打开一个目录和它的子目录，在第三个标签剪切并粘贴到同卷/另一卷。确认两个标签跟随实际新位置，后台标签标题也更新，地址栏和文件行路径一致；再新增一个文件确认监听仍正常。
- 对已在其它标签打开的文件夹执行F2重命名；含子目录标签、仅大小写变化，以及移动的KeepBoth编号目标分别检查。前进/后退使用新位置，不多出一个已消失的旧目录页。
- 同名前缀的相邻目录不被改动，已关闭的标签不被恢复。文件移动、Skip/no-op、失败和跨盘部分移动不让仍存在的来源根跳向目标副本。
- 移动时用户正在进入该目录的子目录，加载应使用新位置；用户正在去别处时保留用户导航。晚到的旧目录加载不覆盖新页。
- 新位置暂时不可读时显示错误并保留旧页；刷新重试已知新位置。随后显式访问被重新创建的旧路径时，正常打开该路径的新目录，不永久重定向。
- 同卷身份未变时保留仍存在的选择，跨盘重新取得身份后清除失效选择；列表/网格与排序保持偏好。位置跟随使用正常目录导航，当前目录搜索按正常导航退出。
- 相关目录监听在操作前暂停与排空；检查等待阶段取消、同名失败/取消、失败后改名续队列，监听能在当前位置恢复。操作期间切换标签、导航和关闭窗口不产生迟到UI，也不暂停其它无关目录监听。

外部performed-effect、Merge/Replace、删除回收站、拖放、属性产品化和后续远端仍待开发，本轮不宣称整项目或综合验收完成。
