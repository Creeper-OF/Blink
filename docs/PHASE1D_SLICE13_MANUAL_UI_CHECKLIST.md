# Slice13 剪切与多项同卷移动人工清单

状态：按用户要求暂缓执行。本清单保留Slice13同卷范围，当前跨盘开发另见[Slice14清单](PHASE1D_SLICE14_MANUAL_UI_CHECKLIST.md)。普通原生回归和编译不能替代下列真实界面、系统剪贴板与外部程序互操作检查。

仅使用普通用户可写的自有测试目录，在同一卷建立source与target。准备两个普通文件、一个含中文名称和子文件的目录，确保与用户文件隔离。

- Ctrl+X或右键剪切后来源完整；进入target再Ctrl+V或背景粘贴才开始移动。Blink内及Explorer到Blink方向确认普通文件和目录混合移动，来源与目标标签都更新。
- Blink剪切后粘贴到Explorer，确认由Explorer执行。未粘贴前来源保留，不因发布剪贴板而删除；外部目标反馈与剪切视觉淡化仍待后续，不作为本轮完成项。
- 目标已有同名文件或目录时显示移动专用冲突。Skip保留当前来源并继续尾项，KeepBoth使用编号名称移动后继续，Cancel保留已完成前缀和未开始尾项；Replace/Merge不可用。
- 移动失败后显式改名重试当前项并续尾项，不重做已经移动的前缀。再次Paste相同MOVE剪贴板序列显示已提交提示；处理原队列或重新剪切，不把旧选择捕获为新来源。
- 原地Paste显示未变更，源和目标均不声称发生移动。已移动后后续检查warning不被描述为失败回滚；工具提示可看到已移动路径及警告数字。
- 多项移动中取消、快速切标签/搜索/导航、A到B再到A、关闭冲突或窗口，不出现迟到提交和第二个操作。取消状态明确区分已完成项与未开始项。
- Ctrl+C/Paste仍可重复复制同一批来源；新建文件夹、F2重命名、原Copy冲突与取消不回退。
- 跨卷MOVE按Slice14清单另行验收；Slice13原“跨卷拒绝”规则仅为历史基线。链接、虚拟项目、特殊存储等不支持输入给出可见错误。
- 中英文环境下移动进度/队列计数、冲突、名称输入、错误与剪切提示无复制专用误标，长路径不撑破窗口布局。

移动后已打开的目录自身地址跟随、external performed-effect反馈/剪切外观、跨卷移动、目录合并/覆盖、拖放、删除回收站、属性产品化和综合真实服务验收不在本轮完成声明内。
