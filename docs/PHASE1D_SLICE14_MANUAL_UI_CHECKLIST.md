# Slice14 跨盘文件及文件夹移动人工清单

状态：按用户要求暂缓；普通原生回归与编译不代替真实界面和剪贴板互操作验收。仅用普通用户可写的C/D自有测试目录，勿使用个人资料。

- 从一个卷剪切普通文件、含中文名称/子目录/空目录的文件夹和混合多项，粘贴到另一卷。确认目标数据正确、来源已移除；来源与目标已打开的标签均更新。只读文件与ADS的自动回归通过，人工可补查目标属性。
- 文件夹目标根已存在时检查Skip、KeepBoth和Cancel。KeepBoth显示实际编号根；现有目标不被覆盖，队列尾项依选择继续或停止。
- 大目录移动期间取消，检查文件已完成部分保留在目标、未开始部分留在来源。显示的目标复制数、来源移除数与实际目录一致，不能提示所有来源仍完整，也不能把整个根计为已移动。
- 文件复制完成但来源移除失败，或所有文件已完成但空来源目录移除失败时，显示实际路径/失败位置。目标副本保留；部分失败的“跳过当前项并继续”只处理未开始尾项，不重复复制当前树。
- 实际文件变化/占用导致失败时保留剩余来源。新加入来源的未计划文件不被递归删除；取消队列也不能回滚已移动文件。
- 从Explorer到Blink的真实跨盘MOVE剪贴板意图、混合文件/目录顺序、同序列重复粘贴提示分别验收；Blink剪切到Explorer的外部目标反馈仍是后续待做项。
- 中英文进度、数量、错误、长路径和工具提示可读；移动时切换标签/导航或关闭窗口无迟到UI更新。Ctrl+C重复复制和原同卷移动不回退。

目录合并/覆盖、删除回收站、拖放、属性产品化、已打开的移动目录地址跟随、外部performed-effect及后续SFTP/网盘不属于本轮已完成声明；整体开发目标继续。
