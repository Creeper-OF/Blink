# Blink 文件管理器

Blink 是一个使用 C++20、C++/WinRT 和 WinUI 3 开发的 Windows 文件管理器，目前仍在开发中。

> 这个项目从 7 月份就开始用 AI 做了，中间因为上学停了一段时间。最近发现 B 站已经有人做出了成品，我开始怀疑到底要不要继续做这个东西，心里很矛盾。

## 已实现

- F3、Ctrl+F/Ctrl+E聚焦搜索并全选；F6/Shift+F6在文件区、地址、搜索、命令、导航和标签间正反切换，保留草稿与选择。 高级搜索输入仍保留Ctrl+F/E搜索入口。
- 地址栏每一级可展开直接子目录，支持向下键、收缩菜单、隐藏项和真实失败反馈；此电脑沿用现有驱动器入口。

- 本地目录与驱动器浏览，多标签、地址栏、前进后退、上级目录及目录变化自动刷新。
- 原生面包屑与长路径收缩、Ctrl+L/Alt+D地址编辑、Enter/Esc导航与回焦、F4真实已提交历史；自动刷新保留输入，切换标签取消未提交草稿。
- 详细信息、列表、网格视图，以及名称、类型、大小和修改时间排序。
- NTFS 的 MFT / USN 索引与多盘搜索；搜索范围跟随当前位置，也能在高级选项中指定盘符、目录和子目录范围。
- 文件与文件夹的新建、重命名、复制、剪切粘贴、同盘和跨盘移动，进度、取消及同名冲突处理。
- F2重命名默认选中文件主名并保留最后扩展名，目录和新建名称保持全选；取消后恢复命令能力和文件列表焦点，Ctrl+A仍可修改全名。 改名成功后自动选中新名称并滚动到该项。
- 普通文件覆盖替换、目录复制与移动合并、回收站删除、确认后的永久删除、拖放及属性统计。
- 普通目录与搜索结果统一的 Blink 风格右键菜单：打开、复制、剪切、粘贴、路径复制、重命名、删除和属性；搜索结果支持定位到所在目录。
- 通过“压缩与更多系统选项…”调用 Windows 完整菜单，兼容 Bandizip 等已安装扩展，支持普通目录多选。
- 顶部标准命令栏提供新建、剪切、复制、粘贴、重命名、删除、排序和查看；更多菜单包含选择、属性、刷新与路径复制，窄窗口自动溢出。查看/显示与右键及各标签状态同步，修复隐藏项目开关导致旧标签无法继续搜索的问题。
- Windows 11 风格标题栏、Mica 背景和随系统切换的浅深色外观。

## 从源码构建

工程/API最低目标：**Windows 11 24H2 x64**；本轮实际开发验证主机为**Windows 11 25H2 x64**、MSVC v143、Windows SDK `10.0.26100.0`。Windows App SDK `2.3.1` 与 C++/WinRT `2.0.250303.1` 通过 NuGet 还原，具体依赖以工程文件为准。

在 Windows PowerShell 中进入仓库目录：

```powershell
.\build.ps1 -Configuration Debug -MaxCpuCount 1
.\build.ps1 -Configuration Release -MaxCpuCount 1
```

构建入口会查找已安装的 Visual Studio C++ Build Tools。运行主程序：

```powershell
& .\src\Blink\x64\Release\Blink.exe
```

本仓库当前提供开发版源码，尚无正式安装包。索引服务需要在索引状态入口中单独启用；服务不可用时本地目录浏览仍可使用。源代码本身不会安装或启动服务。

## 目录

| 目录 | 内容 |
| --- | --- |
| `src/Blink` | WinUI 主界面、导航、搜索和文件操作 |
| `src/Blink.Core` | 文件枚举、元数据及文件身份 |
| `src/Blink.Index*` | 索引、常驻服务和只读查询协议 |
| `src/Blink.FileActivationHost`、`src/Blink.ShellMenuHost` | 系统关联打开和原生菜单承载 |
| `src/Blink.Provider*` | 后续存储接入的原型 |
| `tests`、`scripts` | 测试和构建、验证脚本 |
| `docs` | 功能范围、开发计划及交接记录 |

构建输出、依赖缓存、索引数据库、诊断工具和本机日志均在 `.gitignore` 中排除。
